## 📌 Project Overview

This project focuses on using a Zenmap **For scanning the Network to identify numeber of host(active/inactive) and also (open/closed) serviceports**.
The purpose of the lab project is to use cybersecurity tools, for Network scanning inorder to identify hosts in the network include active and inactive also to identify service ports which are both open and closed with and outside the network.

---


## 🎯 Objectives

The main objectives of this project are to:

- To identify **Local IP** on a LAN.
- Identify list of **live host** in a subnet.
- How many host are live in a subnet.
- Identifying **IP Address of live Hosts**.
- Identifying  **MAC Address** of a live hosts.
- Displaying the output topolgy 

---

## 🛡️ Purpose of the Project

The Purpose of this project is to do Scan the Network inorder to identify the Host in the network as well, Service ports in the network as wll as the Network Topology  by using Kali tool **Nmap** or **Zenmap (_GUI of Nmap_)** which is already pre installed in kali linux.

**Zenmap** is a Graphical User interface (_GUI of Nmap_) tool which is used to for scanning the Network inroder to check and identifying the Hoosts in the network and also numberservice ports hosted in ip addresses in a network.
